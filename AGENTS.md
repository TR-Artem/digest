# Правила проекта «Дайджест новостей»

React 19, TypeScript, Vite 8. Тесты — Vitest 5 и Testing Library. Линтер — oxlint с плагином `jsx-a11y`.

## Команды проверки

```
npx tsc -b
npm run lint -- --deny-warnings
CI=true npm test
npm run build
```

Все четыре должны проходить без ошибок и предупреждений. `npm run build` запускает `tsc -b` и `vite build`.

## Формат данных

Адрес веб-приложения Apps Script лежит в `VITE_DIGEST_URL` (файл `.env`). Ответ:

```json
{
  "news": [
    {
      "id": "https://habr.com/ru/articles/1/",
      "date": "2026-11-16T09:00:00Z",
      "source": "Хабр",
      "title": "Заголовок новости",
      "summary": "Пересказ в двух предложениях.",
      "tags": "ИИ, наука",
      "link": "https://habr.com/ru/articles/1/"
    }
  ]
}
```

`tags` приходит **строкой** через запятую — в приложении это массив строк. `date` — ISO 8601 во всемирном времени. Новости показываются от свежих к старым.

## Правила кода

- Адрес дайджеста берётся только из `import.meta.env.VITE_DIGEST_URL`, в коде его нет.
- Отфильтрованный список вычисляется при отрисовке; в состоянии хранятся только поиск, тег, флажок и отметки «прочитано».
- Отметки «прочитано» — `localStorage`, ключ `digest-read`, массив `id`.
- Сообщение о загрузке — `role="status"`, об ошибке — `role="alert"`, ошибка содержит код ответа.
- Поля формы подписаны `<label>`; карточка — ссылка или кнопка, не `div` с `onClick`.
- Тесты не ходят в сеть: `fetch` подменяется через `vi.stubGlobal`.
- Ключ записи в таблицу (`KEY` Apps Script) и токен бота в проект не попадают.
