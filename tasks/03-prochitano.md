# Задание 3. Отметка «прочитано»

## Что сделать

- У карточки кнопка «Отметить прочитанным»; после нажатия — «Прочитано ✓», карточка становится бледнее.
- Повторное нажатие снимает отметку.
- Отметки хранятся в `localStorage` под ключом `digest-read` (массив `id`) и переживают перезагрузку.
- Флажок «Только непрочитанные» учитывает отметки.

## Правила проекта

- Состояние читается из `localStorage` лениво, при первом рендере.
- Ошибки `localStorage` не роняют страницу: при повреждённых данных список пустой.

## Готово, когда

- `npx tsc -b`, `npm run lint -- --deny-warnings`, `CI=true npm test` — без ошибок;
- тест: отметить новость, размонтировать приложение, показать снова — отметка на месте;
- тест: повторное нажатие снимает отметку.
