# Задание 2. Поиск, тег и «только непрочитанные»

## Что сделать

- Поле «Поиск»: ищет по заголовку и пересказу без учёта регистра.
- Выбор «Тег»: список тегов собирается из новостей, плюс вариант «все».
- Флажок «Только непрочитанные».
- Все три условия действуют одновременно; над лентой счётчик «Показано N из M».
- Если подходящих новостей нет — «Новостей не найдено».

## Правила проекта

- Отфильтрованный список вычисляется при отрисовке, в состоянии не хранится.
- Каждое поле подписано `<label htmlFor>`.

## Готово, когда

- `npx tsc -b`, `npm run lint -- --deny-warnings`, `CI=true npm test` — без ошибок;
- в `src/App.test.tsx` есть тесты на поиск, тег и флажок;
- поиск «ЛЁД» находит новость, где слово есть только в пересказе.
